CSV to JSON converter

Teacher tool. Turn your edited CSV files into the data.json file the site reads.

How to update the site

  1. Edit any of the CSV files in Excel or Google Sheets and save (or download) them as CSV.
  2. Drop the files you changed into the box below. You don't need to upload all of them.
  3. Fix anything listed under “Needs fixing,” then upload the corrected file again.
  4. Select Download data.json and replace the old file in your site's data folder.
